# Phishing Website Detection & Risk Analysis

## Project Overview
An interactive cybersecurity dashboard developed using Power BI to analyze phishing and legitimate website records and identify risk patterns, security weaknesses, and attack methods.

## Dataset
- 5,000 website records
- 80+ cybersecurity-related attributes
- Contains phishing and legitimate website activity

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Excel

## Key Analysis
- Phishing vs legitimate website analysis
- Risk indicators
- Security feature analysis
- Attack types and attack channels
- Threat severity analysis
- Investigation and detection status
- Record-level investigation

## Dashboard
The Power BI dashboard is organized into multiple analytical sections covering:
1. Overview
2. Risk & Indicators
3. Security Weaknesses & Attack Methods
4. Investigation & Detection

## Project Objective
To transform cybersecurity data into an interactive Business Intelligence dashboard that helps identify phishing patterns, understand security risks, and support cybersecurity investigation.
